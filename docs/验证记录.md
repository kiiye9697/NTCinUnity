

## 4. Mask 通道权重

### 4.1 Metalness

Flagpoles 金属遮罩在 16 bpp、loss scale 8 时：

```text
源图均值       201.84
解压后均值      27.46
```

Metalness loss scale 调整为 24 后，bpp 和文件大小保持不变：

```text
解压后均值     201.80
```

NTC 的 bpp 预算由材质全部通道共享。Color 和 Normal 的信息量更高时，近二值 Metalness 容易被训练损失压缩为低对比度常量。`lossFunctionScale` 用于重新分配固定预算中的通道权重。

### 4.2 Smoothness

17 个材质在 Smoothness 1x 权重下，源图和解压图的标准差比值为：

```text
Smoothness 平均约 0.94，最差 Ceiling 0.824
Color      约 0.999
Normal     约 0.98
AO         约 0.987
```

Bake Window 将 Smoothness/Roughness loss scale 默认设为 16。调整后需要重新比较源图与解压图的统计量。

## 5. 数据布局验证

### 5.1 Latent BGRA4 展开

NTC latent 使用 BGRA4。`NtcAssetBuilder` 将每个 16 bit texel 的四个 nibble 按物理顺序展开到 RGBA32。

官方 shader 中的 `.bgra` 用于补偿硬件 BGRA 格式的采样通道顺序。Unity 展开后的 RGBA32 已经完成该排列，因此 `NtcInference.hlsl` 和 `NtcDecompress.compute` 直接使用采样结果，不执行第二次 `.bgra`。

### 5.2 V 轴约定

磁盘导入纹理和 compute 直接写 RenderTexture 的行方向不同。latent 采样、位置编码和训练坐标保持不变，坐标转换位于最终输出或最终查询边界。

### 5.3 TIFF 第四通道

Photoshop 可能将 RGBA TIFF 的第 4 sample 标为 `ExtraSamples=UNSPECIFIED`。Pillow 在这种情况下只暴露 RGB，尽管 alpha 数据仍在 raw tile 中。

Bake Window 检测 `RGBX/RGBXX` raw mode 并重解释为 RGBA，用于读取 MetallicGlossMap.A 和 BaseMap alpha。该兼容路径依赖 Pillow 内部字段，升级 Pillow 后需要重新验证。

### 5.4 Smoothness semantic

Smoothness/Glossiness 数据在 manifest 中使用 `Glossiness` semantic。Runtime 按 texture name 建立通道布局；正确 semantic 用于保证 NTCExplorer 等外部工具不会将光滑度解释为粗糙度。

### 5.5 Alpha Cutout

Alpha Cutout 链路包括：

```text
BaseMap.A
  -> Bake Window 提取 AlphaMask
  -> NTEX 独立通道
  -> NtcPbrChannelLayout.Alpha
  -> compute 写入 BaseColor.a
  -> URP _ALPHATEST_ON
```

缺少 `AlphaMask` 的 `.ntc` 需要重新烘焙。

## 6. 显存测量范围

on-Sample 的资源统计需要覆盖：

- latent `Texture2DArray`；
- weight `ComputeBuffer`；
- BaseColor、Normal、Mask、AO tile cache；
- cache mip 链；
- on-Load 全分辨率 RenderTexture；
- 模式切换后仍保持引用的资源；
- Unity 场景中仍被材质引用的原始贴图。

仅比较 `latent + weights` 和普通贴图不能代表 tile cache 实现的总显存占用。

## 7. 验证范围

已覆盖：

- NTEX 40-byte Header、JSON 和 Data Chunk；
- 无 GDeflate BufferView；
- BGRA4 latent 到 RGBA32 `Texture2DArray`；
- INT8 MLP `48 -> 64 -> 48 -> 32 -> 16`；
- on-Load compute 全图解压；
- on-Sample compute tile cache；
- URP BaseColor、Normal、Metalness、Smoothness、AO 和 Alpha Cutout；
- 场景材质扫描、模式切换和通道调试。

功能限制见 [`技术报告.md`](技术报告.md#11-功能限制)。
