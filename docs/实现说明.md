# 实现说明

## 数据组织

离线压缩由 NVIDIA RTXNTC 完成。Unity 侧通过 `NtcContainerReader` 读取 NTEX Header、JSON 和二进制数据，`NtcAssetBuilder` 根据模型描述构建 latent 纹理数组与网络权重缓冲。

运行时使用 `LoadMetadata` 保留描述信息，上传时按 view 读取 latent 和所选网络数据，避免在材质组生命周期内额外持有整份二进制 chunk。`Load` 保留整块读取的工具接口。两个入口使用相同的尺寸、范围和模型校验。

当前解码器使用 `48 → 64 → 48 → 32 → 16` 的四层 INT8 网络、RowMajor 权重布局和 HGELUClamp 激活。模型校验在 GPU 资源创建之前完成。

`NtcTextureSetAsset` 以源材质的 GUID/local ID 标识纹理组，保存数据路径、材质模板、原材质恢复路径及每张贴图的采样设置。场景控制器序列化 Renderer 和材质槽索引，运行时直接使用资产引用恢复绑定。

## 统一纹理组访问

`NtcMaterialSampling.hlsl` 提供两个入口：

- `LoadMaterialTexel`：按 texel、mip 和寻址模式读取并解码一组通道。
- `SampleMaterialTextures`：处理过滤与通道语义，返回完整 PBR 材质采样结果。

一次 texel 推理返回整组输出。BaseColor、Normal、Metallic、Smoothness/Roughness、AO 和 Alpha 从中取对应通道；具有相同采样设置的贴图共享结果。

采样层处理 Repeat、Clamp、Mirror、MirrorOnce、Point、Bilinear、Trilinear、各向异性等级和 mip bias。UV 变换沿用 URP/Lit 共用 BaseMap ST 的约定。滤波循环使用一个解码调用点。

`NtcMaterialSampling` 在 C# 侧绑定模型、通道和源材质参数，保留 tint、法线强度、光滑度、AO 强度、裁剪及光照开关。源材质启用的贴图缺少对应通道时，控制器使用原材质。

## 运行模式

`NtcSceneController` 负责按材质组管理模式切换和资源所有权。

| 模式 | 资源与处理 |
| --- | --- |
| Original | 原材质与原图 |
| InferenceOnLoad | `NtcDecompressor` 整图解码到 PBR RenderTexture |
| InferenceOnSample | `NtcTileStreamer` 根据可见性、距离和预算调度 tile 解码 |
| InferenceOnSampleDirect | `NTC/LitDirect_URP` 在 fragment shader 中采样 latent 并执行网络 |

Direct shader 接入 URP Lighting，包含 Forward、ShadowCaster、DepthOnly 和 DepthNormals pass。Compute 模式与 Direct 使用相同的容器和通道布局。

## 资源生命周期

Direct 材质替换完成后，控制器可解除对应原材质的引用，再调用 `Resources.UnloadUnusedAssets`。共享纹理通过 Unity 引用关系保留。恢复 Original 时先加载 Resources 中的恢复材质，再替换 Renderer 并释放 NTC 资源。

latent 与权重由纹理组持有；整图解码目标和 tile cache 分别由解码器、streamer 管理。模式切换、停用和销毁时释放对应资源。内存面板按对象去重，统计原图、latent、权重和解码缓存。

## 工具链

`NtcBakeWindow` 在主线程收集材质与资产信息，后台执行图像转换和 CLI 训练，完成后回到主线程创建 Unity 资产。每个任务使用独立临时目录，发布前校验模型格式。

`tools` 中的脚本负责本地工程准备、测试、Player 运行和源码包导出。源码包包含 Runtime、Editor、Shaders、Resources、Tests 与许可证文件。NVIDIA 后端、示例美术、生成数据和本地工作记录独立保存。
