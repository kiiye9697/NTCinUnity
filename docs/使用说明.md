# 使用说明

## 安装

在已配置 Render Pipeline Asset 的 Unity URP 工程中，通过 Package Manager 安装 `unity-plugin/package.json`，或将整个目录复制到 `Assets/NtcPlugin`。复制时保留 `.meta` 文件。

离线烘焙使用 NVIDIA `ntc-cli` 和 Python/Pillow。后端构建步骤见 [RTXNTC README](../nvidia-backend/README.md)；部分 TIFF 输入还需要 `tifffile`。

## 烘焙

打开 `NTC / Bake Window`，配置 CLI、Python、输出目录和纹理源目录。扫描会收集 Renderer 的全部材质槽，按材质对象去重。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| Bits per pixel | 16 | 压缩码率 |
| Training steps | 100000 | 训练迭代次数 |
| Metalness loss scale | 24 | 金属度通道损失权重 |
| Smoothness loss scale | 16 | 光滑度通道损失权重 |
| GDeflate | off | 输出 Unity 解码器读取的 BufferView |

保存材质资产后选择需要烘焙的条目。每个任务会转换输入、生成 manifest、调用 CLI，并在完成后发布 Unity 绑定资产。单张纹理也可以作为输入。

通道提取约定：

| 源属性 | 输出 |
| --- | --- |
| `_BaseMap` | RGB 颜色；按材质用途保存 Alpha |
| `_BumpMap` | 法线 |
| `_MetallicGlossMap.r` | Metallic |
| `_MetallicGlossMap.a` | Smoothness |
| `_OcclusionMap.g` | AO |

发布结果：

```text
Assets/NtcBindings/<GUID_localId>.asset
Assets/NtcBindings/<GUID_localId>_Template.mat
Assets/NtcBindings/<GUID_localId>_Direct.mat
Assets/StreamingAssets/NtcData/<GUID_localId>.ntc
Assets/Resources/NtcOriginals/<GUID_localId>.mat
```

已有 `.ntc` 文件可通过源 Material 的 `Assets / NTC / Bind Existing NTC To Material` 菜单绑定。

## 场景配置

使用 `NTC / Add Scene Controller` 创建控制器。添加、重新烘焙或修改材质后，执行 `NTC / Rescan Scene Materials` 并保存场景。控制器按 Renderer 和材质槽索引恢复绑定。

Direct 对应 `NTC/LitDirect_URP`，使用 URP/Lit 的不透明、Alpha Clip Metallic 工作流。透明、视差、Specular、detail、clear coat、纹理 emission 及自定义 shader 使用原材质。

`releaseOriginalTextures` 控制 Direct 就绪后的原图引用释放。共享消费者仍需使用的原图继续保留；切回 Original 时从 Resources 恢复原材质。

## Player 构建

将保存的场景加入 Build Settings。保留控制器上的 shader 引用、绑定资产和生成的 StreamingAssets 数据；绑定的 Direct 材质模板提供局部 shader variant 引用。当前数据加载方式使用本地文件路径。

## 脚本入口

在仓库根目录执行：

```powershell
# 导出插件源码包
.\tools\Export-NtcPackage.ps1

# 运行不需要外部模型语料的测试子集
.\tools\Run-NtcEditModeTests.ps1 -UnityEditor '<Unity.exe>' -CpuOnly

# 使用25文件模型语料运行完整测试
.\tools\Run-NtcEditModeTests.ps1 -UnityEditor '<Unity.exe>' -Corpus '<corpus>'
```

测试宿主默认位于 `build/ntc-review-tests`，由脚本创建并配置。`-ProjectPath` 用于指定一次性测试工程；Editor 不随附 URP 时可通过 `-UrpVersion` 指定版本。模型测试使用的语料由本地提供。

`Prepare-NtcShowcase.ps1` 同步插件并配置已有的本地示例工程；`Run-NtcBenchmark.ps1` 构建、运行指定 Player 并输出 JSON/CSV。`-ResourceOnly` 用于资源与队列检查，默认运行要求相机渲染。插件包通过 `Export-NtcPackage.ps1` 导出到 `build`。
